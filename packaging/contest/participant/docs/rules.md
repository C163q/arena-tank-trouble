# 基本规则

每局有 2–4 辆坦克，每位参赛者控制一辆。坦克分散出生在随机生成的迷宫内。每辆坦克只有一次生命，车身是会随着朝向旋转的矩形。

## 移动与开火

比赛每秒推进 60 步，每步可同时选择移动、转向和开火。

| 操作 | 含义 |
| --- | --- |
| W / S | 沿车头方向前进 / 后退，一格均需 0.45 秒 |
| A / D | 原地逆时针 / 顺时针转动，一整圈需 1.5 秒 |
| F | 朝车头方向开火 |
| 等待 | 这一步保持静止 |

W 和 S 同时选择会抵消，A 和 D 也一样。坦克先转向，再沿新朝向移动。车身遇到墙或其他坦克会受到阻挡。炮管用于指示方向，命中范围按车身算。

## 弹药和道具

开局有 5 发普通弹。开火消耗一发，弹匣未满时每 3 秒补 1 发。普通弹每秒飞 2.5 格，比坦克前进略快，触墙会反弹，第 10 次触墙后消失。弹丸碰到车身会击毁坦克，反弹后也能击毁发射者。

开局 15 秒后会随机刷出第一批道具，之后每 10 秒尝试刷新，每批 1–2 件，场上最多同时有 5 件。车身与道具重叠即可拾取。捡到道具会替换下一发，新的道具覆盖旧的。发射道具不消耗普通弹。

| 道具 | 效果 |
| --- | --- |
| 激光 | 飞得比普通弹快，第 5 次触墙后消失。路径留下约 0.2 秒的轨迹，碰到轨迹也会被击毁 |
| 散弹 | 朝车头前方同时发射 3 发普通弹，方向和速度各有随机偏移 |

## 收缩区与得分

前 30 秒整张地图安全。之后矩形安全区以地图中心为中心匀速缩小，60 秒时长宽各剩一半，90 秒时缩到一个点。每步移动后，旋转车身只要有任何部分越出安全区就会被淘汰，刚好贴边可以存活。回放里红色区域是危险区。

| 事件 | 分数 |
| --- | --- |
| 击毁另一辆坦克 | 发射者得 1 分，哪怕发射者已出局 |
| 自己的弹丸击毁自己，或因越界出局 | 0 击杀分 |
| 成为最终存活者 | 2 分 |

同一步命中与越界同时发生时，按武器命中结算。只剩一辆坦克后继续模拟 2 秒，弹丸、激光和收缩区依然有效。最后一辆撑过这 2 秒才获胜。全灭为平局，之前拿到的击杀分照常保留。

## 正式评测

参赛 Bot 用同一版本的裁判和相同计分规则对战。一组比赛使用同一张地图轮换出生位。总榜按已完成场次的场均总分排序，完全相同则并列。具体参赛名单、场数和地图种子安排由组织者统一公布。

实现自己的坦克策略，比赛中的决策使用公开观测、自身历史和自有策略数据。参赛者使用原版裁判和计时工具，保持其他参赛者的文件、进程和比赛结果完整。
